# Beacon logo concepts (not adopted yet)

The site still uses the original lighthouse mark (`src/components/site/Brand.tsx`, `public/icon.svg`).

- **Round 1** ([sheet](round-1-directions.png), [shapes](round-1-marks.js)): lighthouse simplified, across, side by side, the lit b, pulse.
- **Round 2: signal fires** ([sheet](round-2-signal-fires.png), [shapes](round-2-marks.js)): a chain of hilltop fires lit one after another, a signal relayed across every team. Options: the range, lit in turn, one beacon. Recommended: **lit in turn**.

Each mark is a 24×24 SVG drawn in the brand palette (ink #17191D, gold #D9A45B, blue #315EFB). The `.js` files hold the exact shapes, so the chosen one can go straight into `BeaconMark`.
